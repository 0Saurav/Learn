# Day 13: Debugging 


The process fo removing bugs from your code

Tips & Techniques to identify bug:

1. Describe the Problem
2. Reproduce the Bug
3. Play Computer
4. Fix the issue
5. Print is Your Friend
6. Use a Debugger (Python Tutor, Thonny)
7. Take a break
8. Ask a friend
9. Keep running your code often
10. StackOverflow or google it
